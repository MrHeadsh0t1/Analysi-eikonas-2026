# Ανακατασκευή παζλ εικόνας

Εφαρμογή ανακατασκευής εικόνας από ανακατεμένα και περιστραμμένα τετράγωνα κομμάτια. Ο χρήστης ορίζει πλέγμα **P γραμμών × Q στηλών**. Το σύστημα συγκρίνει τις πλευρές των κομματιών και αναζητά μια συνολική διάταξη με beam search.

Το έργο περιλαμβάνει κώδικα ανακατασκευής, ποσοτική αξιολόγηση, πειράματα και διαδραστική επίδειξη Streamlit.

## Περιβάλλον και εγκατάσταση

Η ανάπτυξη και οι δοκιμές έγιναν σε Windows με Python 3.14.6. Από PowerShell, μέσα στον φάκελο του έργου:

```powershell
py -3.14 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Την πρώτη φορά που χρησιμοποιείται μέθοδος CNN, το torchvision κατεβάζει τα προεκπαιδευμένα βάρη του ResNet18. Απαιτείται τότε σύνδεση στο διαδίκτυο. Στις επόμενες εκτελέσεις χρησιμοποιείται η τοπική προσωρινή αποθήκευση των βαρών.

## Γρήγορη εκτέλεση

Οι εικόνες δοκιμής βρίσκονται στο `test_images/`. Για δημιουργία παζλ 3×3, ανακατασκευή και αξιολόγηση:

```powershell
.\.venv\Scripts\python.exe puzzle.py --image test_images\forest.jpg --rows 3 --cols 3 --seed 42
.\.venv\Scripts\python.exe solver.py --mode edge
.\.venv\Scripts\python.exe evaluation.py
```

Για πλέγμα 2×3:

```powershell
.\.venv\Scripts\python.exe puzzle.py --image test_images\forest.jpg --rows 2 --cols 3 --seed 42
.\.venv\Scripts\python.exe solver.py --mode combined_deep
.\.venv\Scripts\python.exe evaluation.py
```

Το `puzzle.py` αποθηκεύει τις διαστάσεις στο `output/puzzle_config.json`. Ο `solver.py` και το `evaluation.py` τις διαβάζουν από εκεί. Με κάθε νέα δημιουργία παζλ αντικαθίστανται τα προηγούμενα κομμάτια και η προηγούμενη λύση.

## Μέθοδοι ανακατασκευής

Η επιλογή γίνεται με `solver.py --mode ΟΝΟΜΑ`:

| Μέθοδος | Χαρακτηριστικά που συμμετέχουν στο κόστος γειτνίασης |
|---|---|
| `edge` | Συνέχεια RGB στο όριο και αμφίδρομη πρόβλεψη γειτονικών pixel |
| `combined` | `edge`, ιστογράμματα χρώματος και στατιστικά υφής |
| `deep_only` | CNN περιγραφείς πλευρών και ολόκληρων κομματιών |
| `combined_deep` | `combined` και CNN περιγραφείς |
| `full` | `combined_deep` και τοπικά χαρακτηριστικά Harris / ιστογραμμάτων κλίσης |

Οι μέθοδοι εκτός της `deep_only` χρησιμοποιούν επίσης πρόσθετη ποινή εξωτερικού ορίου όταν ανιχνεύεται πολύ λευκό φόντο. Τα αριθμητικά κόστη διαφορετικών μεθόδων δεν συγκρίνονται απευθείας, επειδή αποτελούνται από διαφορετικούς όρους.

Ο solver εξετάζει τέσσερις περιστροφές για κάθε κομμάτι και χρησιμοποιεί beam search με πλάτος 2.000 μερικών λύσεων. Κάθε κομμάτι τοποθετείται μία φορά. Η αναζήτηση είναι προσεγγιστική και δεν εγγυάται τη βέλτιστη διάταξη.

## Αρχεία εξόδου

Το `puzzle.py` γράφει στον φάκελο `output/`:

- `original.png`: η εικόνα μετά την προσαρμογή στις διαστάσεις του πλέγματος.
- `shuffled.png`: προεπισκόπηση των ανακατεμένων κομματιών.
- `pieces/piece_*.png`: τα κομμάτια που δίνονται στον solver.
- `puzzle_config.json`: διαστάσεις πλέγματος και μέγεθος κομματιού.
- `ground_truth.json`: οι πραγματικές θέσεις και περιστροφές, **μόνο για αξιολόγηση**.

Ο `solver.py` γράφει:

- `solution.json`: σειρά κομματιών και διορθωτικές περιστροφές.
- `reconstructed.png`: ανακατασκευασμένη εικόνα.

Ο solver δεν διαβάζει το `ground_truth.json` ή την αρχική εικόνα για να βρει τη λύση.

## Αξιολόγηση

Το `evaluation.py` υπολογίζει:

1. Ακρίβεια απόλυτης θέσης κομματιών.
2. Ακρίβεια γειτόνων.
3. Ακρίβεια διορθωτικής περιστροφής.
4. Ακριβή ταύτιση pixel με την αρχική εικόνα.

Αναφέρει επίσης τις τρεις πρώτες μετρικές **μετά από ευθυγράμμιση συνολικής περιστροφής**. Για τετράγωνα πλέγματα δοκιμάζει 0°, 90°, 180° και 270°. Για ορθογώνια πλέγματα δοκιμάζει 0° και 180°, επειδή η στροφή 90° αλλάζει τις διαστάσεις του πλέγματος.

Η ευθυγράμμιση χρησιμοποιεί τη γνωστή λύση μόνο κατά την αξιολόγηση. Δεν αλλάζει την έξοδο του solver.

## Διαδραστική επίδειξη

```powershell
.\.venv\Scripts\python.exe -m streamlit run demo.py
```

Στην εφαρμογή μπορούμε να ανεβάσουμε εικόνα, να επιλέξουμε P, Q, μέθοδο και seed, και να δούμε την αρχική εικόνα, τα ανακατεμένα κομμάτια, την ανακατασκευή και τις μετρικές. Μπορούμε επίσης να κατεβάσουμε την ανακατασκευασμένη εικόνα ως PNG.

## Αναπαραγωγή πειραμάτων

Βάλτε τις εικόνες `.jpg`, `.jpeg` ή `.png` στο `test_images/`. Για πειράματα σε τρεις διαστάσεις με seeds 42 και 123:

```powershell
.\.venv\Scripts\python.exe experiments.py --rows 2 --cols 3 --seeds 42 123
Copy-Item .\results\experiment_results.csv .\results\experiment2x3_deep_results.csv

.\.venv\Scripts\python.exe experiments.py --rows 3 --cols 3 --seeds 42 123
Copy-Item .\results\experiment_results.csv .\results\experiment3x3_deep_results.csv

.\.venv\Scripts\python.exe experiments.py --rows 4 --cols 4 --seeds 42 123
Copy-Item .\results\experiment_results.csv .\results\experiment4x4_deep_results.csv
```

Το πρόγραμμα δοκιμάζει και τις πέντε μεθόδους για κάθε εικόνα και seed. Το `experiment_results.csv` αντικαθίσταται σε κάθε εκτέλεση, γι’ αυτό κρατάμε ξεχωριστό αντίγραφο για κάθε μέγεθος πλέγματος.

## Δομή έργου

| Αρχείο | Ρόλος |
|---|---|
| `puzzle.py` | Δημιουργία, ανακάτεμα και περιστροφή κομματιών |
| `features.py` | Απόσταση RGB και συνέχειας πλευρών |
| `classical_features.py` | Χρώμα και υφή |
| `local_features.py` | Τοπικά χαρακτηριστικά Harris και κλίσεων |
| `deep_features.py` | CNN περιγραφείς από προεκπαιδευμένο ResNet18 |
| `solver.py` | Κόστος γειτνίασης και beam search |
| `evaluation.py` | Μετρικές αξιολόγησης |
| `experiments.py` | Πειράματα και εξαγωγή CSV |
| `demo.py` | Διαδραστική εφαρμογή Streamlit |

## Παρατηρήσεις και περιορισμοί

Κάθε κομμάτι είναι τετράγωνο 128×128 pixel, ώστε να επιτρέπονται περιστροφές κατά 90°. Έχουν δοκιμαστεί πλέγματα 2×3, 3×3 και 4×4. Μεγαλύτερα πλέγματα μπορεί να απαιτούν περισσότερο χρόνο και μνήμη.

Στις δοκιμές με τις εικόνες `bird.jpg`, `forest.jpg` και `night_sky.jpg`, καμία μέθοδος δεν υπερείχε σε όλες τις περιπτώσεις. Ιδιαίτερα, η `deep_only` ανακατασκεύασε πλήρως τη νυχτερινή εικόνα σε 3×3, αλλά απέδωσε χειρότερα σε άλλους συνδυασμούς εικόνας και πλέγματος. Τα αναλυτικά αποτελέσματα βρίσκονται στα CSV του φακέλου `results/`.
